# Modelová pravidla 2003: doporučení nejméně 60 %

Nová doporučení vyžadují alespoň 60 % odhadované pravděpodobnosti bez zaokrouhlení.
Platí i pro hlavní 1X2, ELO a modelové kombinace (dříve 58 %, resp. 55 %).
Týmové góly nad 0,5 si ponechávají přísnější práh 78 %. Ostatní podmínky důvěry,
čerstvosti a vzorku se nemění. Pravděpodobnosti modelu se nezvyšují ani nekalibrují
podle přání uživatele; mění se pouze kvalifikační pravidlo.

Nekvalifikované predikce zůstávají v přehledu Všechny predikce pro úplné hodnocení.
Denní výběr, kvalifikovaný seznam a Telegram používají stejný příznak qualified.
Historické verze 2001 a 2002 zůstávají oddělené, dostupné a doběhne jejich settlement.
Žádné přepisování původních publikací, nová migrace ani externí API volání.

Po nasazení spustit predict-upcoming a daily-selection. Nové záznamy vznikají pouze
před výkopem. Hranice 60 % není důkaz skutečné úspěšnosti ani ziskovosti.
